## Relay demo

The working React/TypeScript demo lives in this repository. Run `pnpm install`, then `pnpm dev` and open http://127.0.0.1:5173 in Chrome.

For one-button startup, open Run and Debug in VS Code, select **Relay demo · Chrome**, and press **F5**. If Vite is already running, choose **Relay demo · Chrome (server already running)**.

The workflow is: collect reports → verify them onto the map → generate routes → verify the route plan → explicitly create simulated rescuer alerts. Optional Amazon Bedrock integration extracts reports, asks clarification questions, and reviews server-computed optimal routes. See [Bedrock setup](docs/BEDROCK_SETUP.md) for backend deployment and Amplify configuration. The board remains a browser-memory scenario using a fictional network; real-road routing, persistence, audio transcription and notifications require separate integrations.

See [running the demo](docs/RUN_DEMO.md), [API contract](docs/API.md), and [team workflow](docs/TEAM_WORKFLOW.md).
